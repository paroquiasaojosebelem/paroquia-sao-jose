# V6.17 — Intenções e Pagamentos

1. Execute `paroquia_sao_jose_migracao_v6_17_intencoes_pagamentos.sql` no Supabase.
2. Publique todos os arquivos desta versão na raiz do repositório.
3. No Vercel, aguarde o deploy ficar Ready.
4. Configure valor/PIX/link seguro em Admin > Configurações.
5. Faça uma intenção de teste e use o botão “Informar pagamento realizado”.
6. No Admin > Intenções, confira filtros e altere para “Pago / confirmado” somente após conferência.

A V6.17 não armazena dados de cartão e não confirma pagamentos automaticamente.
