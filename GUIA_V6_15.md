# V6.15 — Agenda Paroquial

1. Execute `paroquia_sao_jose_migracao_v6_15_agenda.sql` no Supabase SQL Editor.
2. Copie todos os arquivos desta versão para a raiz do repositório GitHub, substituindo os existentes.
3. Aguarde o deploy do Vercel.
4. Acesse Admin > Agenda e cadastre o primeiro evento.

Recursos: página pública /agenda, painel /admin/agenda, upload de imagens, eventos com início/término/local/responsável, destaque de próximos eventos na Home.
