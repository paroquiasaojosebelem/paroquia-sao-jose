# V6.16 — Formação e Espiritualidade
1. Execute `paroquia_sao_jose_migracao_v6_16_formacao_espiritualidade.sql` no Supabase.
2. Envie todos os arquivos desta pasta para a raiz do repositório GitHub, mesclando/substituindo.
3. Aguarde o deploy do Vercel.
4. Acesse Admin > Formação e Espiritualidade.
5. Cadastre a primeira publicação. Conteúdos marcados como destaque aparecem na Home.

Categorias: Palavra do Pároco, Formação Católica, Reflexão, Homilia, Oração e Espiritualidade.
A página pública `/formacao` também oferece atalhos para Liturgia Diária e Terço Virtual.
